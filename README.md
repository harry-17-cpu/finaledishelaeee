# Lehumo La Edishela — client-approved rebuild

Responsive, dependency-free static website created for Visual Studio Code. Open `index.html` directly or use the VS Code Live Server extension.

## Pages

- Home, About, Services, Claims, Quote, Contact, Privacy and Terms
- Dedicated pages for Short-Term Insurance Advisors, Business Insurance, Commercial Insurance, Professional Indemnity, Home Insurance, Sectional Title & Body Corporate, Thatch Roof, Agriculture, Hospitality and Event Liability

## Included functionality

- Responsive desktop/tablet/mobile navigation and dropdown
- Large high-resolution Lehumo logo
- Local project images featuring Black South African clients and professionals
- Scroll reveals, card/button hover motion and reduced-motion support
- Testimonial slider with no portrait images
- WhatsApp popup linked to 061 449 8437
- Quote, contact and claim forms with browser validation
- Cookie preference notice and back-to-top control
